# 当前真机漆膜检测逻辑

适用于 `robot_task.launch.py`、到站/最后阶段诊断及 `robot_task_oline.launch.py` 共用的真实检测器。
参数以 [robot_task.yaml](../../src/robot_task_control/config/robot_task.yaml) 为准；
独立 `detect_control/config/detect.yaml` 的默认值可能不同，不要混为一套参数。

## 哪些已到真机，哪些仍只在仿真

| 功能 | 真机现状 |
|---|---|
| 相机点转基座探针目标、安装补偿 | 已接入，依赖正确的相机坐标/外参 |
| 3 cm 预接近、沿工具 +Z 限力接触、测厚、撤离 | 已接入真实 MoveIt/力传感器/测厚串口 |
| 每个点测完返回同一拍照关节原位 | 已接入 |
| 离站按中间点二→中间点一→过渡位2→过渡位1→行车位返回 | 主任务/到站诊断已接入；online full 收到 go_home 或有效电量低于10%后返程充电；过渡位2的180°肘角尚需满足真机限位 |
| 绕拍照工具自身 Z 轴选角度，Z 轴方向不变 | 真机使用 15° 步长有限候选；仿真 axis_only 是连续自由绕轴的终点约束试验，尚未同步真机 |
| 仿真预接近运动 | 只保留 axis_only，MoveIt 直接求终点轴向约束；途中不锁姿态，最后固定所选朝向直线接近/撤离 |
| 仿真照片、接触力、漆膜厚度 | 不模拟，不产生真实测量 |

当前固定的是拍照时 tool0 +Z 的基座方向，不再锁死拍照时的完整朝向。
允许在预接近规划前绕这根轴选角度，但选定后最后直线接触/撤离保持完整朝向不再变化。
前面的 OMPL 绕障不持续锁轴；没有把工具 +Z 改成基座竖直 Z。
有限候选不保证一定可达，仿真不能代替硬件接触测试。

## 一点如何测完

1. 拍照停稳，冻结当次 `base_link→camera_frame` 和探针姿态，记录实际六轴拍照原位。
   相机毫米点换算成基座探针接触目标；点固定后不随机器人后续运动再次变换。
   底盘或工件移动后须重新采集，不能复用旧点。
2. 补偿 `tool0→probe` 安装变换，保持拍照工具 +Z 方向，检查绕自身 Z 的无碰撞候选。
   沿工具 +Z 的反方向退 **3 cm** 得到预接近点，MoveIt 先规划绕障到这里。
3. 检查实际工具/探针到位和朝向，冻结实际 tool0 的局部 +Z 在基座中的方向。
   真机接触段使用导纳沿该方向推进，预接近到名义点为 **2.5 mm/s**，越过名义点继续寻找接触为 **1 mm/s**；MoveIt反向撤离速度上限为 **3 mm/s**。
   检测预接近及回拍照位的关节速度/加速度比例均为 1%，阶段超时 300 秒；过渡点及普通中间点速度不变。
   预接近选角、运动及到位确认阶段：三轴合力达到 `preposition_force_limit=25 N` 即取消运动、进入 FAULT，人工确认后重新发起任务；启动前检查仍用 `initial_force_limit=15 N`。
   MoveIt 模式同时检查未滤波的去偏合力，不能靠滤波掩盖瞬时受力；此软件保护并非安全认证急停，仍有采样及制动延迟。

拍照及运动启动前，TF 仍须满足时间戳年龄 `[-0.1, 0.3]` 秒。短时缺少新鲜 TF 时暂停流程，
最多等 1 秒重新取得新鲜的相机与探针 TF，并与原冻结位姿比较；等待期间不发布目标、不启动检测。
持续超时或实际位姿变化则取消本轮；检测运动中的力、TF及安全检查不放宽。
此等待仅处理暂时延迟，不证明发布端断流问题已解决；报错会附具体 frame 和 TF 年龄。

图像稳定检查失败或采集取消时，最后收到的有效新帧保存为
`capture.output_dir/failed/<会话ID>/camera_image_last_UNVERIFIED.png`（海康），
同目录 JSON 记录失败原因、帧计数和变化量；没有有效帧时仅保存 JSON。
这些图片仅用于查看，不进入正式照片索引、不发送，也不能据此继续检测。
   名义点前 30 mm 开始低速，未接触可越过名义点最多额外 **50 mm**，不是无上限继续压。
   因而未提前触力时接近路径上限约为 80 mm；额外探入限制本次没有增大。
4. 去零偏的未滤波轴向力达到 **20 N**，在力回调中立即请求取消轨迹，不等待低通滤波或下一次推进定时器；
   滤波轴向力也保留20 N停止检查。确认旧动作结束且新关节反馈持续停稳后才能进入 HOLD。
   原始去零偏三轴合力达到 **25 N**、力数据超过 **0.3 秒** 不新鲜等条件走保护停止，
   不等同于正常接触完成。采样、通信和制动有延迟，20 N 不是保证瞬时力正好止于该值，不能保证不触发硬件保护。
5. 保持位置 **2.5 秒**，触发 `/detactor/acquire_trigger`，仅关联本次保持开始后的有效新读数。
   这是停止推进、保持位置，不是闭环恒定20 N；没读到数不能把上一点缓存当本点结果。
6. 沿冻结轴反方向撤离，按检测器保护条件确认安全，再用关节目标回到记录的拍照原位。
   确认关节到位、外力回落后发布包含读数和 `returned_home` 的逐点结果，再处理下一个点。

接触轴是 tool0 自身 +Z，**不是 base_link 的竖直 Z，也不是自动估计的工件表面法向**。
只有该工具轴与表面法向对齐时，才能称为垂直接触表面；仅有 XYZ 坐标不足以保证这一点。
当前工具 +Z 与模型探针轴的关系来自安装 TF，实际装配仍须核对。

## 朝向保持的边界

真机当前 `preposition_rp_tolerance_deg: [0,0]`、`preposition_tool_z_spin: true`，
先试原角度，再按 15° 步长检查 ±15°、±30°……180°。每个候选保持尖端接触 XYZ 和工具 +Z 方向，
重新补偿安装偏移并计算3 cm预接近点，预接近及名义接触目标都要通过无碰撞 IK。
随后 OMPL 检查到预接近点的路径，选中端点 IK 不等于保证整段规划成功。
`lock_tool_orientation: false` 仅表示前面整段 OMPL 绕障不持续锁姿态，
不是终点朝向无限制；预接近到位检查以及最后接触/撤离仍约束选定朝向。
探针长度会收紧工具姿态误差预算，以免工具小角误差在尖端放大。

3 cm是探针目标到预接近位置沿接近轴的距离，不是固定距基座高度，也不是探针长度。
当相机 +Z 与拍照 tool0 +Z 平行且同向时，当前相机点 `(0,0,10) cm` 的预接近点就是 `(0,0,7) cm`；
代码先换算到基座，再减去 `0.03 × 拍照工具Z单位向量`，与上述相机坐标计算等价。
预接近点和接触点都指探针尖端，tool0 还必须补偿安装长度。
仿真只保留 axis_only 终点轴向约束，其他对照已清理，详见[仿真说明](../simulation/PATH_PREVIEW.md)。

## 结果、重试和返回

主任务串口 `/dev/ttyUSB0`、115200；测厚单位必须按仪器确认设置，`unknown` 不擅自换算为微米。
逐点结果由 `/detect_controller/point_result` 发布，经 9010 回传并由麒麟保存；
成功需要本次有效读数及回位确认，不能仅凭 TCP 受理 ACK 或“接触到了”认定测量成功。

目标不可达、行程用完、缺少本次读数等可恢复分支，须确认停止和安全条件，再做受保护回位；
回位后仍会报告失败/需重试，不伪报成功。oline 会等待麒麟下一条 detect，重新采图取点，
不会自行循环重测；原单轮协调器保留其重试约束，本地固定点不伪造新观测。
超载、保护锁、状态断流或安全条件不满足则停止，不保证自动撤回或回家。

正常检测回拍照位，不等于整机回家。完整中间点返回见[任务指南](ROBOT_TASK_GUIDE.md)，
远程多轮与 go_home 条件见 [oline](../tcp/OLINE流程与协议.md)。
历史独立检测接口仍保留在[归档](../archive/detect_control_README.md)，实际阈值以当前主配置为准：轴向20 N，三轴合力25 N。

## 与旧工作区 ros_ws2 的检测控制对比

本机未找到名为 ros2_ws 的目录；此次只读比较的是之前保存的 ros_ws2，未修改旧工作区。
比较对象为旧 `camera_detection_real.yaml`、`camera_probe_touch.yaml` 和 `detect_controller.py`，
不是旧通用 detect.yaml 的基座 -Z 默认，也不是仅用于测试的导纳配置。

| 项目 | ros_ws2 相机触碰 profile | 当前 ros_ws 真机 |
|---|---|---|
| 执行方式 | OMPL 到预接近＋一次笛卡尔直线，执行期间限力取消 | 相同的 MoveIt force guard，不是改成另一种恒力伺服 |
| 预接近目标朝向 | 直接约束完整拍照工具朝向 | 固定工具 Z 方向，15° 步长绕自身 Z 选候选，再约束选定完整朝向 |
| 绕障途中 | lock_tool_orientation=false，不持续锁朝向 | 同样不持续锁朝向 |
| 预接近距离 | 2 cm | 3 cm |
| 最后接近速度 | 2 mm/s | 到名义点2.5 mm/s，名义点后1 mm/s；撤离上限3 mm/s |
| 接触停止阈值 | 20 N | 20 N（去偏未滤波轴向力也直接触发） |
| 保持/额外探入 | 5 秒／名义点外最多 5 cm | 2.5 秒／名义点外最多 5 cm |
| 检测器内部关节姿态调度 | joint_postures_enabled=true，检测前经中转，撤离后经中转回行车位 | false；先回拍照关节原位，再由外层工作流倒序经过中间点离站 |

两版相机点转换函数及末端安装 Xacro 相同；但旧本地点分别为 `[15,15,160] mm` 或
`[-5.370267,-3.820747,275] mm`，当前 arrival_detect 是 `[0,0,100] mm`，拍照起始姿态也须逐次核对。
不能因旧点曾经成功，就断言当前点在新距离及朝向下应当可达。
旧版同样按探针长度收紧完整朝向容差，并非仅有宽松的 1° 或完全无姿态约束。
旧版完整姿态对照已移除，仿真不再保留多套试验控制入口。
